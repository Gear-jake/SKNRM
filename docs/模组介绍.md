# SKNRM（SKN Remake）· WorldBox 性能模组

> 适用版本：WorldBox **0.51.2（build 719）** · 加载器：**NeoModLoader 1.2+**
> 当前版本：**1.5.4** · 平台：PC（Steam / owl）
> 仓库：https://github.com/Gear-jake/SKNRM

---

## 一句话介绍

**让上万单位的世界也能流畅跑起来的纯性能模组**——不改变玩法、不替换画面，只降低后台重复计算。

---

## 它解决什么问题

WorldBox 的单位一多，卡的不是画面，而是**每个单位每帧都在完整跑一遍 AI 管线**：
决策 → 寻敌 → 任务校验 → 行为执行 → 状态检查。8000 个单位时，这条管线一秒跑 8000 次，
其中大部分单位这一帧其实"没什么事可做"。

SKNRM 做的事就是：**把重复的、无害的计算摊开或跳过**，同时保证"该动的单位一定在动"。

---

## 主要功能

### 1. 分级 AI 节流
只对**静止、当前无事可做**的平民按相位降频（默认最多 1/8 帧）。
**永不节流**：军队、军队队长、国王、城市领袖、正在赶路、正在执行动作、缺兵城市的市民。

### 2. 好东西：连动物都能省
可选开关「完全禁用非智慧动物 AI」：野兽、怪物不再思考与移动（最省算力）。
**被"赋予智慧"的动物不受影响**——按亚种（`Subspecies.isSapient`）与王国（`Kingdom.isCiv`）判定，
狼人、熊人、蟹人照常工作。

### 3. 逻辑 job 分帧
只把**纯数值模拟**类 job 摊开（属性、饥饿、冻结、计时器、成年、孵化），每 3 帧一次。
决策、任务校验、寻敌、地块动作**一律每帧执行**。

### 4. 城市轮转（UPP）
城市按相邻成簇分桶轮转思考，省城市 AI 开销。
**豁免**：有军队、被围攻、首都、交战中、缺战士的城市一律不轮转（保证征兵与防守）。

### 5. 渲染与 UI 节流
- 地图层热点节流：实测 `DebugLayerCursor` 7–10ms/帧 → 1.5–3ms
- 单位层绘制与本体渲染**同相位**（不会出现图标错位、不跟随）
- 鼠标 UI 命中缓存、纪元卡片节流（对操作无感）

### 6. GC 择机（消除随机爆卡）
关掉自动 GC，堆到阈值或玩家暂停时回收一次。
把 WorldBox 里那种**毫无预兆的 1–3 秒卡死**变成可控回收。

### 7. 读档宽限
进大存档后 12 秒内市民轻度节流，避免"读档头几秒完全卡住"。

### 8. 防崩补丁（8 项）
空投射物、远程空投射物、坏装备精灵、名牌 LOD、资源精灵兜底 ×2、
进攻行为空目标（原版 `BehCityActorCheckAttack` 不判空）、读档钩子。

### 9. 帧率解锁 + FPS 显示
默认解开垂直同步与帧率上限（可设上限），左上角显示实时帧率。
**高帧率不会让游戏变快**（已分离模拟速度与渲染帧率）。

## 实测数据（本机 · 960×704 地图）

| 场景 | 原版/未优化 | 使用 SKNRM |
|---|---|---|
| 6,442 单位（无节流基线） | 角色 **1,108 ms** → 0.9–1.6 fps | 角色 **10–30 ms** |
| 6,708 单位（job 分帧前后） | 角色 10.2 ms / 30.3 fps | 角色 **7.1 ms** / **42.3 fps** |
| 6,711 单位 | 32 fps | **48–54 fps** |
| 8,832 单位 | — | 平静 **102 fps** / 交战 13–16 fps |
| 小型世界（417 单位） | — | **116–122 fps**（闸门关，行为=原版） |

> 数字会随地图大小、单位数、是否交战、其它模组而变；上表是同机同存档的对照结果。

## 设计原则（为什么它不容易出问题）

1. **行为优先**：所有玩法相关的节流都受「人口阈值」控制——没到阈值时**完全按原版跑**。
2. **视觉同相位**：任何影响画面位置的降频都与本体同帧刷新，不会错位或抖动。
3. **不重写原版方法**：优先"少调用"，而不是"抄一遍逻辑"，避免漏分支。
4. **自动共存**：安装前检测目标方法是否已被别的模组补丁，有则**自动让路**并写日志——
   和整合包里 400+ 补丁的大型模组也能共存。
5. **关键单位白名单**：军队/国王/领袖/赶路/动作中一律满速。

## 安装

1. 安装 **NeoModLoader 1.2+**（放到 `worldbox_Data/StreamingAssets/mods/`）；
2. 游戏内开启 **实验模式**；
3. 把 `SKNRM` 文件夹放进 `worldbox/Mods/`；
4. 启动游戏，日志出现 `[NML]: [SKNRM]: Loaded` 即成功。

**卸载**：删除 `Mods/SKNRM` 文件夹即可，不写入存档、不留残留。

## 设置

游戏内按 **F7** 打开设置页：**36 项**（24 个开关 + 12 个滑条），常用数值都能直接拖：

| 滑条 | 说明 |
|---|---|
| 人口阈值 | 超过多少单位才开始节流（默认 1000） |
| AI 节流上限 | 最多降到 1/N 帧（默认 8） |
| 逻辑 job 分帧周期 | 默认 3 |
| 军队 / 待业市民 / 交战国平民 节流 | 各自的放宽周期 |
| 可见对象步长、单位层步长 | 视觉相关，默认偏保守 |
| 寻敌缓存帧、城市桶容量 | 扫描与轮转 |
| GC 硬上限、最大帧率 | 内存与帧率 |

不想调？默认值即为"行为优先"的保守配置。

## 兼容性

- 与 **任何模组共存**：启动前自动检测补丁点，冲突则让掉自己那一项并记日志；
- 已审计过的整合包场景：400+ 补丁的大型模组（如近代战争系列）、经济类、UI 类模组；
- 想彻底排除干扰：把 `SafeMode` 设为 `true`，一键关掉所有玩法节拍改动。

---

## 不支持

- **手机版**：能编译、能加载资源，但加载程序集时原生崩溃（详见 README 第 13 节实测记录），暂不适配；
- **0.22.9 / owl 版**：本模组只针对 719。

---

## 已知代价

- **内存不变**：大地图的活堆（如 960×704 约 1.8GB）主要是引擎每格对象，模组无法降低；
  SKNRM 只负责把 GC 停顿挪到可控时机。
- **节流会带来轻微反应延迟**：人口越多、阈值越低，单位决策间隔越长。行为异常时先看 F7。
